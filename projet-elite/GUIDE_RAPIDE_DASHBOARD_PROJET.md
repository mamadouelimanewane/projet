### En dessous : 4 graphiques
1. **Progression Prévue vs Réelle** → Êtes-vous en avance ou retard ?
2. **Répartition des Tâches** → Combien faites/à faire/en cours ?
3. **Budget par Catégorie** → Où va l'argent ?
4. **Taux d'Achèvement par Priorité** → Les urgentes sont-elles faites ?

### En bas : Actions
- 🔴 **Alertes** : Problèmes à résoudre
- ◆ **Jalons** : Où en êtes-vous ?

## 📊 Interprétation rapide SPI/CPI

| Valeur | Signification | Action |
|--------|---------------|--------|
| **SPI ≥ 1.0** | ✅ Dans les délais | Continuez |
| **SPI 0.9-0.99** | ⚠️ Léger retard | Surveillez |
| **SPI < 0.9** | 🔴 Retard important | Agissez maintenant |
| **CPI ≥ 1.0** | ✅ Sous budget | Excellent |
| **CPI 0.9-0.99** | ⚠️ Légère dérive | Contrôlez |
| **CPI < 0.9** | 🔴 Dépassement | Réduisez coûts |

## 💡 Astuces Pro

### 1️⃣ Vérifiez chaque matin
- Ouvrez le dashboard en arrivant
- Regardez les 5 KPIs en 10 secondes
- Si tout est vert → journée tranquille
- Si rouge → investiguez immédiatement

### 2️⃣ Utilisez les graphiques pour communiquer
- **Réunion client** : Montrez "Progression Prévue vs Réelle"
- **Comité direction** : Montrez SPI/CPI + Budget
- **Équipe projet** : Montrez Tâches par Priorité

### 3️⃣ Naviguez efficacement
```
Dashboard Projet
    ↓ (problème détecté)
Cliquez sur ⚠ Problèmes
    ↓ (analyse)
Cliquez sur 📊 Gantt pour réviser planning
    ↓ (action)
Cliquez sur 👥 Ressources pour réaffecter
    ↓ (retour)
Bouton ← Retour au dashboard
```

### 4️⃣ Comparez dans le temps
- Prenez des screenshots hebdomadaires
- Comparez SPI/CPI semaine après semaine
- Montrez la tendance à votre management

## 🎓 Exemple concret

### Scénario : SPI = 0.85 (retard 15%)

**1. Diagnostic (30 secondes)**
```
Dashboard → SPI = 0.85 🔴
→ Cliquez sur ⏱ Délais
→ 3 tâches en retard identifiées
```

**2. Analyse (2 minutes)**
```
Délais → 
- Tâche A : +5 jours (cause: attente client)
- Tâche B : +8 jours (cause: sous-estimation)
- Tâche C : +3 jours (cause: intempéries)
```

**3. Action (5 minutes)**
```
→ Cliquez sur 👥 Ressources
→ Ajoutez 2 personnes sur Tâche B
→ Cliquez sur 📊 Gantt
→ Réorganisez les dépendances
→ Retour Dashboard → SPI remonté à 0.92 ✅
```
