### 4. Formules Appliquées aux Données

Le manuel calcule avec les **vraies formules** que l'application utilise :

**Exemple : EVM**
```
Dans l'application (data) :
PV = 450 000 000
EV = 420 000 000
AC = 410 000 000

Dans le manuel :
SPI = EV / PV = 420M / 450M = 0.93 ⚠️
CPI = EV / AC = 420M / 410M = 1.02 ✅

Interprétation :
→ SPI < 1 : Retard de 7%
→ CPI > 1 : Sous budget de 2%
```

**Résultat** : L'utilisateur comprend les CALCULS et leur signification
