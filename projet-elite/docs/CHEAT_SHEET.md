# 📊 FORMULES ESSENTIELLES

## Triangle de Fer
```
        QUALITÉ
          /\
         /  \
  DELAI ----- COÛT
  
Modifier l'un = Impacter les autres !
```

## EVM (Earned Value Management)
```
SPI = EV / PV    (Performance Délai)
👉 SPI < 1 = RETARD ⚠️
👉 SPI > 1 = EN AVANCE ✅

CPI = EV / AC    (Performance Coût)
👉 CPI < 1 = DÉPASSEMENT ⚠️
👉 CPI > 1 = SOUS BUDGET ✅

EAC = Budget Total / CPI   (Coût Final Estimé)
```

## Estimation PERT (Three-Point)
```
Estimation = (Optimiste + 4×Réaliste + Pessimiste) ÷ 6

Exemple : (10 + 4×15 + 25) ÷ 6 = 15.8 jours
```

## Score de Risque
```
Score = Gravité (1-5) × Probabilité (1-5)

🟢 1-4   : Faible
🟡 5-9   : Moyen
🟠 10-15 : Élevé
🔴 16-25 : Critique
```

# 💡 RÈGLES D'OR

## Les 10 Commandements du Chef de Projet

1. ✅ **Tu planifieras** en détail, mais resteras flexible
2. ✅ **Tu communiqueras** sans relâche (90% du job !)
3. ✅ **Tu géreras les risques** activement, pas passivement
4. ✅ **Tu protégeras le périmètre** contre le scope creep
5. ✅ **Tu estimeras** avec réalisme, pas avec espoir
6. ✅ **Tu impliqueras le client** régulièrement
7. ✅ **Tu documenteras** les décisions importantes
8. ✅ **Tu célébreras** les victoires de l'équipe
9. ✅ **Tu apprendras** de chaque projet (REX)
10. ✅ **Tu utiliseras** les bons outils (Projet Élite !)

# ⚠️ PIÈGES CLASSIQUES & SOLUTIONS

| Piège | Symptôme | Solution |
|-------|----------|----------|
| **Effet Tunnel** | 6 mois sans voir le client | Livrer un MVP en 3 semaines |
| **Scope Creep** | "Juste une petite feature en plus" | Change Request formel |
| **Wishful Thinking** | "On peut le faire en 2 semaines !" | Buffer 20% + données histo |
| **Micromanagement** | Chef contrôle chaque détail | Objectifs clairs + confiance |
| **Hero Culture** | Heures supp. permanentes | Meilleure planification |
| **Single Point of Failure** | 1 seule personne sait faire X | Formation croisée + doc |
| **Documentation Zéro** | "On documentera à la fin" | 2h/jour réservées pour doc |
| **Client Fantôme** | Client invisible pendant 3 mois | Revues bi-hebdo obligatoires |

# 📈 INDICATEURS D'ALERTE

## 🚨 Signaux que le projet va mal

- SPI < 0.85 pendant 2 semaines consécutives
- CPI < 0.90
- > 3 problèmes critiques ouverts
- Vélocité équipe en baisse depuis 2 sprints
- Score moral équipe < 70/100
- Client ne répond plus aux emails
- 3+ demandes de changement en 1 semaine
- Équipe fait régulièrement des heures supp.

## ✅ Signaux que le projet va bien

- SPI entre 0.95 et 1.05
- CPI entre 0.95 et 1.10
- < 5 problèmes ouverts (aucun critique)
- Vélocité stable ou en hausse
- Score moral équipe > 80/100
- Client participatif et satisfait
- Changements rares et bien documentés
- Équipe travaille aux heures normales

# 🎯 OBJECTIFS SMART

Chaque objectif de projet doit être :

- **S**pécifique : Clair et précis
- **M**esurable : Quantifiable
- **A**tteignable : Réaliste
- **R**elevant : Aligné avec la stratégie
- **T**emporel : Avec une deadline

**Exemple** :
- ❌ "Améliorer la comptabilité"
- ✅ "Réduire les erreurs comptables de 80% d'ici le 30 juin 2026 en automatisant la saisie des factures"
