## 🎓 PARCOURS D'APPRENTISSAGE RECOMMANDÉ

### Pour un Débutant Complet (20 heures sur 5 semaines)

#### Semaine 1 : Les Bases (4h)
1. **Lire** `INDEX_DOCUMENTATION.md` (30 min)
2. **Lire** `CHEAT_SHEET.md` - Sections clés (1h)
3. **Lire** `MANUEL_COMPLET_PROJET.md` - Chapitres 1-2 (1h30)
4. **Explorer** l'application : Dashboard, Multi-Projets (1h)

#### Semaine 2 : Planification (5h)
1. **Lire** `MANUEL_COMPLET_PROJET.md` - Chapitre 3 (2h)
2. **Consulter** `NAVIGATION_MANUEL.md` - Phase 2 (30 min)
3. **Pratiquer** : Gantt, Tâches, Budget, Risques (2h)
4. **Remplir** `CHECKLIST_PROJET.md` - Phases 1-2 (30 min)

#### Semaine 3-4 : Exécution & Suivi (7h)
1. **Lire** `MANUEL_COMPLET_PROJET.md` - Chapitres 4-5 (3h)
2. **Pratiquer** : Kanban, Agile, KPI, EVM (3h)
3. **Étudier** les cas réels (30 min)
4. **Passer** le Quiz dans le Guide (30 min)

#### Semaine 5 : Clôture & Avancé (4h)
1. **Lire** `MANUEL_COMPLET_PROJET.md` - Chapitres 6-8 (2h)
2. **Explorer** modules IA (1h)
3. **Clôturer** le projet test avec REX (30 min)
4. **Archiver** la checklist complétée (30 min)
